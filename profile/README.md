# Coulee LLC

Coulee LLC is a holding company that owns and operates small software companies.

Each company does one defined job:

- **LeadLumo** — Google-presence management for home-service shops: review requests after every job, professional review replies, Google posts, listing upkeep, and a one-page monthly report. [leadlumo.com](https://leadlumo.com)
- **Path of Truth** — a Bible learning app built as a game, taught in plain words for ordinary and new readers. In development.
